Release notes

What changed in each version of OnionzWeb. The newest is at the top.

Version 0.1.0 beta (dev 8) 21 November 2026Latest

  • The browser runs at Tor Browser's Safest security level.
  • Links that open a new window open a new tab, up to eight. Long-press a link to see its full address, open it in a new tab or copy it.
  • A banner shows the new address when a link takes you to a different onion site, with a tick for bookmarked sites.
  • New private session restarts with a fresh browser profile and fresh Tor routes.
  • The back gesture works on Android 16, and the screen makes room for the status bar, gesture bar and keyboard.

Checking your download

The file for version 0.1.0 beta (dev 8) is called OnionzWeb.apk. It is 154.8 MB (154,824,164 bytes). Its SHA-256 checksum is:

9cda44e229987feef98160439ac7aaf39d4d7a420151819abbddd12a5036e470

On Windows, run certutil -hashfile OnionzWeb.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
